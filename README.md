# NiceNIC API Integration Samples

This repository provides sample scripts and integration examples for using the **NiceNIC Domain API** across multiple programming languages.

---

## Examples Included

* **Python**: Domain registration and status checks
* **PHP**: Reseller account API integration
* **Node.js**: Domain renewal automation
* **cURL**: Quick examples for testing API endpoints

---

## Getting Started

1. Sign in to your NiceNIC account and obtain your credentials from [API Settings](https://nicenic.com/user/api_setting.php).
2. Review the [Domain API documentation](https://nicenic.com/reseller/apiv2.php) for authentication, request parameters, and response codes.
3. Follow the integration examples for your preferred programming language.
4. Test your integration using the [API Sandbox](https://nicenic.com/reseller/apiv2.php?api_type=sandbox&sandbox=1) with Sandbox credentials before switching to production.

## API Endpoints

* **Production:** https://api.nicenic.net/v2/
* **Sandbox:** https://sandbox-api.nicenic.net/v2/

Use the credentials matching your selected environment.
